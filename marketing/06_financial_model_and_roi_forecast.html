## 1. Executive Summary: The Pure-Margin Advantage

Most software-as-a-service (SaaS) businesses fail because their infrastructure costs scale linearly with user growth. If a complex simulation requires heavy server GPUs or expensive cloud databases, high traffic can bankrupt a startup overnight.

Siliquarium operates on an extraordinary dual-architecture financial model:

  1. 1. Client-Side Free Tier: The vast majority of top-of-funnel users (95%+) run simulations client-side in their browser Web Workers and WebGL canvases. Static files are served via global CDNs (Cloudflare Pages / GitHub Pages) at virtually $0.00 marginal cost per visitor.
  2. 2. High-Value Hosted Pro & Server Infrastructure: Users who pay for Laboratory Pro ($34.99 lifetime or $7/mo) and The Abyssal Arena ($9.99/$19.99) utilize persistent headless simulation execution (src/server/HeadlessSimulationHost.ts). Because the Node.js engine is strictly optimized and zero-dependency, a single $40/month Hetzner or Fly.io instance can support hundreds of continuous headless background worlds.
  3. 3. Merchant of Record Efficiency: Lemon Squeezy handles 100% of global tax remittance and credit card processing for 5% + $0.50 per transaction.

The result is an enviable software profile: Gross Margins exceed 97%, and Net Profit Margins consistently hover between 91% and 94%.
